ゆるコーデ

1. サービス概要

ゆるコーデは、毎朝の服選びで悩んでしまう人の意思決定疲労を軽くするWebアプリです。

天気やシチュエーションに合わせて、手持ちの服からコーディネートを提案してくれます。評価機能で自分の好みを学習していくので、使えば使うほど自分好みのコーデが見つかるようになります。

2. このアイデアはどこから生まれたか

2-1. きっかけとなった体験・感情

私自身、長年毎日の服装に悩まされてきました。朝出かけるときに、どの色とどのアイテムを組み合わせればいいか分からなくて、いつも同じような組み合わせになってしまいます。

また、選択障害の傾向があり、選択肢がたくさんあるとどうしても迷ってしまい、最終的には何も決められずに時間だけが過ぎてしまうことがよくあります。

SNSで見かけるおしゃれなコーデを見ると「自分もこんな風にカッコよく決めたいな」と思うのですが、体型の悩みもあり、ただ真似するだけではうまくいきません。体型の欠点を隠しつつ、スタイリッシュに見せるような組み合わせが知りたいと思っています。

2-2. なぜそれが「気になった」のか

私はもともと決断力が弱くて、何を決めるのにも時間がかかるタイプです。服装だけでなく、昼ご飯を決めるのも、仕事で優先順位をつけるのも苦手です。

「毎朝30分も服選びに時間を使うのは、もったいないな」と。もっと大切なことに時間を使いたい、という思いがずっとありました。

3. 課題の整理

3-1. 表に見えている困りごと

毎朝何を着るか決めるのに時間がかかる
同じような組み合わせばかりになってしまう
似合う組み合わせが分からない

3-2. 本当に解決したい課題は何か

なぜ毎朝服選びに時間がかかるのか？

→ 選択肢が多すぎて決められないから
なぜ選択肢が多いと決められないのか？

→ 自分に似合う組み合わせが分からないから
なぜ似合う組み合わせが分からないのか？

→ 試行錯誤する機会が少ないし、失敗したくないから

→ 本当に解決したい課題：自分に似合う組み合わせが分からず試行錯誤が続く中で、自分好みのスタイルを自動的に理解・提案してくれるパートナーのような存在があること

4. 想定ユーザーについて

4-1. 想定しているユーザー

年齢：25〜30代
理由：社会人になると朝の時間が限られるようになり、服装に時間をかけてられない場面が増えるからです
生活・状況：一人暮らしの会社員で、通勤が必要な毎日。平日は残業も多く、朝の準備時間はだいたい30分程度です
理由：朝の限られた時間で服装まで決められず、毎朝ストレスを感じています。アプリで提案してもらえれば、考える時間を大幅に減らせます
環境：通勤電車やオフィスではある程度服装のマナーが求められますが、おしゃれとビジネスのバランスが自分では分かりません
理由：場面（通勤、会議、デートなど）に合わせて提案してもらえるので、マナーを気にせず選べます

4-2. 自分とユーザーの距離

自分自身です。私自身がまさにこの課題を抱えていて、同じ悩みを持つ人に届けたいと思っています。

4-3. 実際に使われる可能性について

最初に使いそうな人：私の周りの友達（同じように朝の服装で悩んでいる人）
思い出す場面：朝起きて「今日何着よう...」と迷ったとき
代わりに使っているもの：今はSNSでコーデを検索したり、同じ服を繰り返し着たりしています
置き換えてまで使う理由：SNSは情報が多すぎて、自分に合うものを探すのが大変です。このアプリは手持ちの服から提案してくれるので、探す手間がゼロです

4-4. ユーザーがサービスを導入して利用するまでのイメージ

きっかけ：朝の服装で迷ってストレスを感じているときに、このアプリを知る
最初の一歩：手持ちの服5着だけテキストで登録（5分程度）
続ける理由：使えば使うほど自分の好みを学習してくれて、提案の精度が上がります。朝の準備時間が短くなるのを実感できます

5. 既存サービス・競合調査

5-1.似たサービスの調査

サービス名：XZ
URL：https://xz-style.com/
できること：クローゼット管理、天気連動コーデ提案、カレンダー機能、1週間分のコーデ提案

5-2. それでも自分が作りたい理由

XZを使ってみたとき、正直「登録が面倒だな」と感じました。写真を撮って、色を選んで、カテゴリを選んで...という作業がすごく手間でした。

また、提案されるコーデが「なんとなく自分じゃない」と思うことが多かったのですが、なぜそう思うかをフィードバックする手段がありませんでした。

「服選びを楽にしたいだけなのに、なんでこんなに手間がかかるのだろう」という違和感がありました。

5-3. 差別化を「体験価値」で表現する

このアプリは、【他のコーデアプリで不満を抱えている人】の【「自分好みのスタイルが見つからない」という悩み】を一番解決するアプリです。

差別化ポイント：

嗜好学習で「自分専用」に進化する：提案されたコーデに評価をつけることで、システムがユーザーの好みを理解し、提案精度が上がる。「使えば使うほど自分専用になる」体験を提供
場面（デート、会議など）を選んで提案：一般的なアプリは天気・気温だけだが、本アプリは外出目的も考慮して提案
テキスト入力で簡単登録：既存アプリは写真撮影が中心で手間がかかるが、本アプリはテキストでも登録可能

6. このサービスで提供したい価値

6-1. ユーザーの変化

行動の変化：毎朝の服装選びの時間が30分から5分に短縮
気持ちの変化：「何着しよう...」というモヤモヤから解放される
考え方の変化：服装は「悩むもの」から「アプリが自分に合ったものを選んでくれる」に変わる

6-2. 価値を一文で表す

「このサービスはコーデアプリに満足できなかった人が、使えば使うほど自分好みのスタイルが見つかるようになるサービス」

7. このアプリで実現すること

MVPで作る機能

テキスト入力による電子クローゼット機能
天気・シチュエーションを指定したコーデ提案
コーデへの評価機能（嗜好学習）

本リリースで作る機能

画像認識による自動洋服登録
音声入力
長期間着ていない服の通知
体型別のコーデ提案（梨型・苹果型などユーザーの体型に合わせた扬长避短のスタイリング）

8. このアプリの懸念点とその対策

懸念点①：ユーザーが登録を面倒に感じる

何が問題になりそうか：手持ちの服を1枚ずつ登録するのが面倒で、途中でやめてしまう可能性がある
なぜそう思うか：既存アプリを見ていて、写真撮影や項目選択がすごく手間だと感じたから
考えている対策：
MVPではテキスト入力だけに絞って、5分で登録完了を目指す
最初は5着だけでも使えるようにして、徐々に増やしていける設計にする
必須項目を最小限にして、任意項目は後から追加できる柔軟性を持たせる

9. 今後の展開・発展の方向性

ユーザーはなぜ使い続ける？ → 使えば使うほど自分の好みを学習してくれて、提案精度が上がるから
続けることで何が変わる？ → 毎朝の準備時間が短くなり、ストレスが減る
データが溜まると何ができる？ → 「今週一番着た服」「お気に入りコーデ」などの統計機能
今考えている発展案：
画像認識で自動登録
長期未着用の服をリマインド
季節の変わり目に「そろそろこの服が活躍します」のお知らせ
体型別コーデ提案（梨型・苹果型などユーザーの体型に合わせた扬长避短のスタイリング提案）

10. 技術スタック

10-1. 使用予定の技術

フレームワーク：Ruby on Rails 7.0.3.1
DB：SQLite
使用予定ライブラリ：Devise（認証）、Bootstrap（UI）

10-2. 技術選定の比較検討

表格
候補	採用/不採用	理由
Ruby on Rails	採用	学校で学んでいて基礎がある。Rubyは文法がシンプルで初学者に優しく、日本語の文献も豊富なため学習しやすい
Django	不採用	Pythonも魅力的だが、学校のカリキュラムがRails中心であり、すでに学習を始めているため
Spring	不採用	Javaは学習コストが高く、卒業制作の期間内にキャッチアップが難しいと判断
MySQL	不採用	学校で学んだが、MVP段階では小規模な単一ファイル型DBで十分。環境構築の手間を省き、開発に集中できる
SQLite	採用	単一ファイル型で環境構築が簡単。MVPは大規模アクセスを想定しないため十分。卒業制作に最適
Bootstrap	採用	CSSを一から書く手間を省き、短期間でレスポンシブなUIを作成可能。日本語チュートリアルも充実
React	不採用	MVPの機能に高度なフロントエンドは不要。学習コストが増え、技術構成が複雑になるため

今回チャレンジしたい点：Deviseを使った認証機能、ActiveStorageを使った画像管理、Yahoo!天気APIとの連携
不安な点：API連携が初めてなので、ドキュメントを読んで理解できるか少し心配です
